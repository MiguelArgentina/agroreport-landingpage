# AgroReport landing page estática

Landing page de validación para AgroReport (sin framework, sin build, 100% HTML + CSS).

## Cómo usar

1. Abrí `index.html` directamente en tu navegador.
2. No necesitás instalar dependencias.

## Cómo editar contenido

- **Textos/copy:** editá `index.html`.
- **Colores y estilo base:** editá variables en `styles.css` dentro de `:root`.
- **Links de WhatsApp:** buscá `wa.me` en `index.html` y reemplazá URL y mensaje.

## Publicación económica recomendada

- GitHub Pages
- Netlify
- Vercel (sitio estático)
- Cloudflare Pages

## Notas

- Esta página está pensada para validación y feedback, no para anunciar un lanzamiento final.
- Se puede evolucionar luego a una app completa según respuestas de usuarios.
